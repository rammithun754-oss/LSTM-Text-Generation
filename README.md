# ✍️ Text Generation using LSTM (PyTorch)

A Natural Language Processing (NLP) project built using PyTorch and Long Short-Term Memory (LSTM) networks to generate text word-by-word.

This project demonstrates the foundations of language modeling and text generation, which are the building blocks behind modern Large Language Models (LLMs).

---

# 🚀 Features

✅ Text Tokenization

✅ Vocabulary Creation

✅ Word-to-Index Mapping

✅ Sequence Generation

✅ Word Embeddings

✅ LSTM Language Model

✅ Text Generation

✅ NLP Pipeline Implementation
